# About ArchPilot

ArchPilot is a system design canvas for turning an application idea into an editable architecture diagram.

Describe the system you want to build, review the generated components and connections, and refine the design in a project workspace. The repository contains the React editor, canvas interactions, backend API, background jobs, and supporting documentation.

The project is maintained in the [ArchPilot GitHub repository](https://github.com/Iamahmedforreal/ArchPilot).
